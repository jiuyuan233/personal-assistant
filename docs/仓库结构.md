# 仓库结构

目录布局照搬 [jiuyuan233/wool-gathering](https://github.com/jiuyuan233/wool-gathering)（只抄结构，不抄功能）：
`scripts/` 放采集与渲染，`data/` 放机器生成的状态，`docs/` 既是文档目录又是 GitHub Pages 根，
`.github/workflows/` 放调度。**参考仓库只读，永远不要往里提交。**

```
personal-assistant/
├── AGENT.md                  维护交接说明（下一个 AI 先读这个）
├── DEV_GUIDE.md              从零部署：建仓 / Secrets / 首次验证
├── CHANGELOG.md              版本记录
├── README.md                 ★生成物：按截止时间排序的任务清单
├── .gitignore
│
├── .github/workflows/
│   ├── assistant.yml         主工作流：单入口 + 模式分发 + 提交 + 飞书
│   └── feishu-test.yml       只测飞书卡片，不碰任何数据源
│
├── scripts/
│   ├── main.py               ★唯一入口：python scripts/main.py <mode>
│   ├── utils.py              北京时间 / 倒计时解析 / ID / JSON / 日志脱敏
│   ├── ai_client.py          OpenAI 兼容客户端：限流、重试、三级 JSON 抽取
│   ├── prompts.py            用户画像 + 三套提示词（公告 / 日记 / 详情）
│   ├── dedup.py              ★合并层：公告旧值优先，任务新值优先
│   ├── study_collector.py    学习通：登录 → 课程 → 铸 token → 作业/考试列表
│   ├── diary_collector.py    Gitee API 读日记：复选框 + AI 挖名言/计划
│   ├── notice_collector.py   公开公告页：翻页 + 日期抽取 + 关键词门 + AI 打分
│   ├── schedule_parser.py    WakeUp .ics → 事件 / 课程聚合 / 本周课表
│   ├── render_readme.py      ★零网络零 token：README + docs/data/*.json
│   ├── week_svg.py           手写 SVG 周课表（无图形库依赖）
│   ├── notify_feishu.js      飞书互动卡片（契约照搬 Lottery 仓库）
│   ├── readme_template.md    README 模板，{{占位符}} 由 render_readme 填充
│   └── requirements.txt      requests + pycryptodome（仅两个）
│
├── data/                     ★除 sources.json 外全是生成物，不要手改
│   ├── sources.json          ●唯一可手改的数据文件：站点 / 关键词 / 接口地址
│   ├── study/
│   │   ├── tasks.json        全部作业+考试任务（含已完成的）
│   │   ├── courses.json      课程列表 + 每门课的待完成数
│   │   └── meta.json         上次尝试/成功时间、ok、失败原因
│   ├── diary/
│   │   ├── quotes.json       名言
│   │   ├── plans.json        潜在计划（state 可人工改）
│   │   └── state.json        每个 md 文件的 sha → 增量判断依据
│   ├── notice/
│   │   └── notices.json      公告 + 相关度评分
│   └── schedule/
│       ├── events.json       186 条单次上课记录
│       ├── courses.json      按 (课程,专题,教室,教师,星期,节次) 聚合
│       └── this_week.json    当前教学周的课
│
├── assets/
│   └── WakeUp导入课表.ics     ●用户提供的原始课表，换学期时替换它
│
└── docs/                     GitHub Pages 根目录
    ├── index.html            任务看板（读 docs/data/*.json）
    ├── css/style.css
    ├── js/app.js             前端只做展示分桶，排序权威在 Python
    ├── week.svg              ★生成物：本周课表图
    ├── data/                 ★生成物：前端数据快照
    │   ├── tasks.json        任务 + stats
    │   ├── meta.json         week / stats / sources
    │   ├── notices.json
    │   ├── plans.json
    │   └── quotes.json
    ├── 技术路径.md            每个选型的理由、被否决方案、实测证据
    ├── 工作原理.md            一次运行的完整数据流
    ├── 数据结构.md            所有 JSON 字段定义
```

★ = 每次运行都会被重写并提交，手改必被覆盖。
● = 人工维护的输入。

## 依赖方向

```
utils ─┬─> dedup ─┬─> study_collector ─┐
       │          ├─> diary_collector ─┤
ai_client ─> prompts                   ├─> main ─> render_readme ─> week_svg
       └──────────> notice_collector ──┘         (只读 data/，不联网)
                  schedule_parser ────┘
```

`render_readme.py` 和 `week_svg.py` **不 import 任何采集器**，也不 import `ai_client`。
这是「finalize 模式零 token」的结构保证——改代码时别把这条线接回去。

## 加一个新数据源要动哪些文件

1. `scripts/<name>_collector.py`：产出 `list[dict]`，字段对齐 [数据结构.md](数据结构.md)
2. `scripts/dedup.py`：选一种合并策略（易变的用新值优先，稳定的用旧值优先）
3. `scripts/main.py`：`COLLECT_MODES` + `HANDLERS` 各加一项
4. `.github/workflows/assistant.yml`：加一条 cron + `case` 分支
5. `data/sources.json`：把可调参数放进去，别硬编码
6. `scripts/render_readme.py` + `readme_template.md`：加展示区块
7. `scripts/notify_feishu.js`：`TASK_TEMPLATES` 加指标正则
8. `docs/数据结构.md` + `AGENT.md`：同步文档
